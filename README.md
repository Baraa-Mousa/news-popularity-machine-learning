# News Popularity Prediction

## About the Project

This project was part of the Machine Learning workshop organized by Qafza. It focuses on predicting news popularity using machine learning techniques and the Mashable dataset.

The project involves working with data, understanding the relationship between different features, selecting the most relevant ones, and building classification models to predict whether an article is popular or not.

## Tools & Technologies

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Google Colab

## Project Steps

- Data Loading and Exploration
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Selection using Mutual Information
- Train/Test Split
- Model Training and Evaluation
- Model Comparison

## Models & Results

| Model | Accuracy | ROC AUC |
|---|---:|---:|
| Baseline | 53.2% | 0.500 |
| Logistic Regression | 64.1% | 0.694 |
| Random Forest | 66.6% | 0.729 |

Random Forest achieved the best results among the tested models.

## Conclusion

This project demonstrates how machine learning can be used to analyze news data and predict article popularity. It also highlights the importance of data preprocessing, feature selection, and model evaluation.
